# Numerology Web

A small numerology project for browser usage through `public/index.html`.

## Requirements

- Node.js 20 (see `.nvmrc`)
- npm

## Quick Setup

1. Use the Node version from `.nvmrc`:

```bash
nvm use
```

2. Install dependencies:

```bash
npm install
```

3. Build browser bundle:

```bash
npm run build
```

## Project Structure

```text
src/
	core/         # Shared numerology + validation logic
	tools/        # Standalone utility modules
	web/          # Browser source entrypoint
	index.js      # Project entrypoint

public/
	index.html
	styles.css
	app.js        # Generated by build
```

## Web Usage

1. Build web bundle:

```bash
npm run build
```

2. Open `public/index.html` in browser.

For active rebuilds while editing web code:

```bash
npm run dev
```

To run UI with local server:

```bash
npm start
```

For preview only (without rebuilding):

```bash
npm run preview
```

## Scripts

- `npm run build` → build web bundle
- `npm run dev` → watch + rebuild web bundle
- `npm run preview` → run local web server at `http://localhost:4173`
- `npm start` → build, then run local web server
- `npm run check` → syntax checks for key source files
- `npm run ci` → run checks and build (same as GitHub pipeline)

## Notes

- Node version is pinned via `.nvmrc` and `engines` in `package.json`.
- `public/app.js` is generated output and should be rebuilt after changes in `src/web/app.js`.
- GitHub Actions pipeline is defined in `.github/workflows/ci.yml`.
