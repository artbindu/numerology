# Numerology Studio

A browser-based numerology application for calculating and exploring numerology values from names and dates of birth, including an interactive Lo Shu Grid calculator.

🌐 **Live Demo:** https://artbindu.github.io/numerology/

## Features

* Name numerology calculation
* Date of birth numerology
* Interactive traditional 3×3 Lo Shu Grid with digit frequencies
* Missing and repeated number analysis
* Clickable number interpretations with separate Driver and Destiny meanings
* Life Path / Destiny calculations
* Numerology number breakdown
* Letter-to-number mapping
* Interactive browser-based interface
* No backend or database required
* Works directly from GitHub Pages
