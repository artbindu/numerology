# Numerology Studio

A browser-based numerology application for calculating and exploring numerology values from names and dates of birth.

🌐 **Live Demo:** https://artbindu.github.io/numerology/

## Features

* Name numerology calculation
* Date of birth numerology
* Life Path / Destiny calculations
* Numerology number breakdown
* Letter-to-number mapping
* Interactive browser-based interface
* No backend or database required
* Works directly from GitHub Pages
